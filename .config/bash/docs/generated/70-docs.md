### __bash_docs_load

Lazily loads the Bash documentation helper implementation.

#### Exit codes

* **0**: The helper was loaded or had already been loaded.
* **1**: The helper file was missing or could not be sourced.

#### Output on stdout

* No output on success.

#### Output on stderr

* Missing documentation helper errors.
